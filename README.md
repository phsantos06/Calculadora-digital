# Calculadora Digital

Calculadora com visual de terminal verde, feita com HTML, CSS e JavaScript — sem `eval()`.

**Acesse:** https://calculadora-phsantos06.vercel.app

## Recursos
- Operações básicas, porcentagem (`200 + 10% = 220`), inverter sinal e apagar
- Correção de ponto flutuante (`0,1 + 0,2 = 0,3`) e separador de milhar
- Aviso de divisão por zero
- Histórico dos últimos 30 cálculos (clique para reutilizar)
- Suporte completo ao teclado: números, `+ - * /`, Enter, Backspace, Esc
